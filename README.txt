SHUBHAM HEXOR - e-Dispatch Office Finder

Phone use:
1. Upload this folder to any static HTTPS host (e.g. Vercel).
2. Open the HTTPS link in Chrome on Vivo T3 5G.
3. Chrome menu -> Add to Home screen / Install app.
4. Camera -> photo -> suggested office.

IMPORTANT:
- Office matching uses the 540-entry master list compiled from the screenshots you supplied.
- OCR uses Tesseract.js from jsDelivr, so the first OCR use needs internet.
- After the app shell and office list are cached, the app itself can open offline; OCR may still require the OCR library to be cached by the browser.
